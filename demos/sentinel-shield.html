A quick field guide to what powers the project.
i
🗂 What's in the package

index.html is the front end. api.py can serve the trained ML ensemble using your phishing dataset.

🔑 Password checker

Local rule-based analysis covering length, common passwords, dictionary words, username reuse, repetition and character variety.

🎣 Phishing & domain analysis

When the API is reachable, URLs use the trained ensemble plus typosquat and brand checks; otherwise the browser uses a transparent heuristic.

🧭 AI assistant

Uses the configured backend/OpenAI connection when available, with a local fallback.

📦 Extension

The extension source can be loaded unpacked from the extension folder.
